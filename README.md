# Pixal

All the convenience of Google Photos. None of the cloud.

Pixal is a local-first photo manager for the library you already have: timeline,
people, search, maps and memories, with every photo, face and place kept on your
machine. No account, no cloud, no tracking.

This repository hosts Pixal's installers.

## Download

**[Download Pixal for Windows](https://pixal.caspx.in/download)**
· [All platforms](https://pixal.caspx.in/downloads)
· [What's new](https://pixal.caspx.in/changelog)
· [All releases](https://github.com/Nouman-wp/pixal-releases/releases)
· [Website](https://pixal.caspx.in)

Run the installer (`Pixal-Setup-v<version>.exe`), follow the setup wizard, and
open Pixal from the desktop shortcut or the Start Menu. On first launch Pixal
sets up everything it needs, including Python if it isn't installed.

If Windows shows "Windows protected your PC", choose **More info → Run anyway**.
That warning appears for any installer Windows hasn't seen downloaded often
yet. Each release lists SHA-256 checksums in `SHA256SUMS.txt` so you can check
that your download is the real one.

macOS is coming soon. Some releases carry an early Mac build for testing; it
isn't supported yet, so the website doesn't offer it. Linux builds appear on the
[downloads page](https://pixal.caspx.in/downloads) as releases include them.
